# מכלול

כל המערכות שלך, מכלול אחד.

## העלאה ל-GitHub Pages (אפשר גם מהאייפד)

1. שמור את ששת הקבצים באותה תיקייה באפליקציית "קבצים".
2. ב-github.com: פלוס למעלה, New repository. שם: `mikhlol`. לבחור Public וללחוץ Create repository.
3. בריפו החדש: Add file ואז Upload files. לבחור את כל ששת הקבצים ולאשר עם Commit changes.
   הקבצים צריכים להיות ישר בריפו, לא בתוך תיקייה.
4. Settings ואז Pages. תחת Branch לבחור `main` ואת התיקייה `/ (root)`, ולשמור.
   אחרי דקה-שתיים מופיעה למעלה הכתובת, בערך `https://שם-המשתמש.github.io/mikhlol/`.
5. לפתוח את הכתובת ב-Safari, ללחוץ על כפתור השיתוף ולבחור "הוסף למסך הבית".
6. לפתוח את מכלול מהאייקון במסך הבית, לבחור שם משתמש וסיסמה, ולהדביק את מפתח ה-API בהגדרות.

## חשוב באייפד ובאייפון

- לעבוד תמיד מהאייקון במסך הבית ולא מלשונית ב-Safari. הם שומרים נתונים בנפרד, ו-Safari עלול למחוק נתונים של אתר שלא נפתח שבוע.
- הנתונים שמורים במכשיר, מוצפנים. כדי להעביר מהמחשב: בהגדרות במחשב "הורד גיבוי", לשלוח את הקובץ לאייפד, ובהגדרות באייפד "ייבא גיבוי" עם אותה סיסמה.
- קישור לקבצים במחשב וגיבוי אוטומטי לתיקייה זמינים רק בכרום ובאדג' במחשב.

## עדכון לגרסה חדשה

להעלות את `index.html` החדש לאותו ריפו (Add file, Upload files) ולאשר. הוא מחליף את הישן.
כדאי גם להעלות את המספר ב-`sw.js` בשורה `mikhlol-v1`, כדי שהגרסה החדשה תגיע מהר לכל המכשירים.
